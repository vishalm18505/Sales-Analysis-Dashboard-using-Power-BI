# Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive sales analysis dashboard built with **Microsoft Power BI**. It brings key business metrics and visualizations into one report to help users explore sales performance, product quantity, brand-wise costs, and state-wise sales.

## Dashboard Features

- **KPI Cards:** Displays Total Sales, Total Cost, Total Profit, and Quantity.
- **Category-wise Quantity Sold:** Compares the quantity sold across product categories.
- **State-wise Sales Map:** Visualizes sales by state to explore geographic patterns.
- **Brand-wise Cost Breakdown:** Uses a pie chart to compare total cost across brands.
- **Supervisor Slicer:** Lets users filter the report by supervisor, depending on the visual interactions configured in Power BI.

## How to Open the Project
1. Download or clone this repository.
2. Open `pdpro.pbix` using **Microsoft Power BI Desktop**.
3. If prompted, refresh the data source or update its path/credentials.
4. Use the supervisor slicer and other interactive visuals to explore the report.
